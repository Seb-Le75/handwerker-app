# Handwerker Service App

MVP fuer die digitale Vor-Ort-Auftragserfassung in SHK-Betrieben.

## Start

```bash
npm install
npm run dev
```

Die Anwendung nutzt Next.js App Router, TypeScript, TailwindCSS und shadcn/ui-nahe Komponenten. Kunden und Auftraege werden lokal im `localStorage` gespeichert.

## Struktur

```text
src/
  app/
  components/
  components/ui/
  data/
  hooks/
  lib/
  types/
```
